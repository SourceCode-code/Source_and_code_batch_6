# JAVASCRIPT ASSIGNMENTS

This folder contains the **JavaScript assignment files** for the Source & Code batch. Each assignment file follows the same structure:

- **Title header** with topic, references, and rules
- **RULES / INTERVIEW RULES** for each section
- **Numbered questions (Q1, Q2, ...)** with tasks described as comments
- **`HINT` / `THINK` / `TEST` comments** to guide you
- **`expected` outputs** in comments for verification
- **Submission checklist** at the end of each file

## How to Run

Each assignment file is a standalone JavaScript script. Open a terminal in this folder and run:

```bash
node 12_ASSIGNMENT_JS_JSON.js
```

Replace `12_ASSIGNMENT_JS_JSON.js` with the filename you want to run.

---

## Conventions Used

1. **Header** - File title, topic, references to lecture/theory notes, and how to run.
2. **Intention sections** - `RULES`, `INTERVIEW RULES` for study discipline.
3. **Questions** - Numbered `Q1`, `Q2`... each with a task, hints, and expected outputs.
4. **Comment style** - Tasks, hints, TESTs, and expectations are written as comments so the file runs without errors.
5. **Submission checklist** - Final self-checklist for each assignment.

## Legend

| Code in comments | Meaning |
|------------------|---------|
| `expected -> ...` | The correct output or result to check against |
| `HINT -> ...` | A hint to help you solve the question |
| `THINK -> ...` | A prompt to think deeply about the concept |
| `TEST -> ...` | A test case to try |
