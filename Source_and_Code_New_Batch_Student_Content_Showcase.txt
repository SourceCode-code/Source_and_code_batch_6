SOURCE & CODE — NEW BATCH
=============================
SOFTWARE TESTING & AUTOMATION
STUDENT CONTENT SHOWCASE

Welcome to your learning journey.

This is not just a course where you watch lectures and write a few scripts.
The goal is to take you from the fundamentals of Software Testing to
real-world Automation Testing, framework development, project work,
and interview readiness.

Your journey will follow:

UNDERSTAND
    ↓
PRACTICE
    ↓
AUTOMATE
    ↓
BUILD
    ↓
TEST REAL PROJECTS
    ↓
PREPARE FOR INTERVIEWS


WHAT WILL YOU LEARN?
====================

You will build your skills step by step across the complete QA / Automation
Testing workflow.


01. SOFTWARE TESTING FUNDAMENTALS
=================================

You will first understand how a professional Software Tester thinks and
works before moving into automation.

YOU WILL LEARN:
- What is Software Testing?
- Why do we need Testing?
- SDLC and STLC
- Verification vs Validation
- Functional and Non-Functional Testing
- Different Testing Types
- Test Scenario
- Test Case
- Test Data
- Bug / Defect
- Bug Life Cycle
- Severity vs Priority
- Smoke Testing
- Sanity Testing
- Regression Testing
- Retesting
- Test Design Techniques
- Agile and Scrum
- Jira basics

WHAT YOU WILL BE ABLE TO DO:
You will be able to understand a requirement, identify testing scenarios,
write effective test cases, report defects and participate in an Agile
testing process.

WHAT YOU WILL BE ABLE TO DO:
You will be comfortable reading, writing and debugging JavaScript code

YOU WILL LEARN:

05. API TESTING

Modern QA engineers need to understand both UI and backend testing.

YOU WILL LEARN:

- Client and Server
- Request and Response
- HTTP methods
- GET
- POST
- PUT
- PATCH
- DELETE
- Status codes
- Headers
- Request body

WHAT YOU WILL BE ABLE TO DO:

06. DOM & WEB FUNDAMENTALS
==========================

Before becoming strong in automation, you need to understand how a web
page is built.

YOU WILL LEARN:
- HTML basics

- Elements
- Attributes

- Inspecting web elements

WHAT YOU WILL BE ABLE TO DO:
You will understand what you are actually automating instead of depending
only on copy-paste locator techniques.


07. TEST DATA MANAGEMENT
========================

Real automation projects require reliable and reusable data.

YOU WILL LEARN:
- What is test data?
- Static vs dynamic test data
- Test data generation
- Reusable data
- Random data
- Environment-based data
- Managing user credentials safely
- Using data inside automated tests
- Data-driven testing concepts

WHAT YOU WILL BE ABLE TO DO:
You will learn how to design automation that does not depend on manually
entering the same data for every test.


08. TEST AUTOMATION FRAMEWORK
=============================

The goal is not to write 100 scripts.

The goal is to build an automation solution that can be maintained by a
team.

YOU WILL LEARN HOW TO:
- Organize automation projects
- Create reusable components
- Separate test logic from page logic
- Manage test data
- Create utilities
- Configure environments
- Generate reports
- Reduce duplicate code
- Improve framework maintainability
- Follow practical coding standards

WHAT YOU WILL BE ABLE TO DO:
You will start thinking like an Automation Engineer rather than someone
who simply writes test scripts.


09. REPORTING & DEBUGGING

Automation is useful only when the team can understand the result.

YOU WILL LEARN:

- Identifying automation issues

HOW EACH TOPIC WILL BE TAUGHT
=============================

Every important topic follows this cycle:

1. UNDERSTAND
   Learn the concept and why it is used.

2. SEE
   Understand a practical example.

3. CODE
   Write the solution yourself.

4. PRACTICE
   Solve an exercise or assignment.

5. APPLY
   Use the concept in a realistic testing scenario.

6. EXPLAIN
   Learn how to discuss it in an interview.

This means you are not expected to simply remember the topic.
